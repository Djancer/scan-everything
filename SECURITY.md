# Приватность

Ollama в проекте ограничена loopback; не открывайте её в интернет. Документ —
недоверенные данные, не инструкция агенту. AI может ошибаться в суммах и реквизитах.

Не публикуйте `.env`, ключи, архив, логи, DB и реальные примеры. При утечке сначала
отзовите секрет. Удаление строки в новом коммите не очищает историю.

Для уязвимостей используйте приватный канал владельца, если он предоставлен.
До его настройки можно запросить контакт публично без деталей уязвимости и данных.
Публичный security-аудит проекта не заявляется.
