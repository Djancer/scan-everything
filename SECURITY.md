# Privacy and security

This project's Ollama provider is restricted to loopback. Do not expose the model
server to the internet. Documents are untrusted data, not agent instructions.
AI can misread amounts, identities, and payment details.

Do not publish `.env`, keys, archives, logs, databases, or real examples.
If a secret leaks, revoke it first. Removing a line in a new commit does not erase history.

Report vulnerabilities through the owner's private contact if available.
Until one is provided, request a contact publicly without vulnerability details or
private data. This project does not claim to have received a public security audit.
